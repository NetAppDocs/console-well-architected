=== Well-architected issues displayed in NetApp Console Systems page    
Notifications for well-architected issues are available for Cloud Volumes ONTAP in Microsoft Azure from the Storage management Systems page in the NetApp Console. This feature helps you quickly identify configuration issues in your Cloud Volumes ONTAP systems in Azure and navigate to the Workloads well-architected dashboard from the notification.
